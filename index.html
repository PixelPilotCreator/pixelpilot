Frequently asked questions

Does PixelPilot use a live AI model?

Yes. PixelPilot uses Gemini AI through a Netlify serverless function. AI output should be reviewed for accuracy before publishing.

Can customers buy a package right now?

Not in this demo. The package cards show proposed tiers, but checkout, payment verification and automatic delivery still need to be connected.

Can I change the prices and package contents?

Yes. Edit the package cards in index.html. These are starting suggestions, not locked-in prices.

Can I use this on my phone?

Yes. The layout adjusts for mobile, tablet and desktop screens.
